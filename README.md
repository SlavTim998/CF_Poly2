# CF_Poly — расширение оригинального QW_Poly

Основа: предоставленный архив QW_Poly-main.zip. Сохранены исходная структура, оформление, страницы, логика мастера и оригинальные функции. Добавлено окно Codeforces Import & Online Test Lab, генерация тестов и экспорт ZIP/JSON.

## GitHub Pages
Workflow `.github/workflows/pages.yml` собирает Vite и публикует `dist`. В репозитории включите Settings → Pages → GitHub Actions.

## Важно
Оригинальные функции Polygon требуют локального прокси (Vite) и **не будут работать непосредственно на GitHub Pages**: нужна отдельная серверная часть и защищённая авторизация. Не вводите секрет Polygon на публичном сайте. Codeforces API предоставляет лишь метаданные и может блокировать браузерные запросы по CORS. Полный текст задачи вводится вручную. Генератор создаёт файлы, но не выполняет произвольные C++ программы.
